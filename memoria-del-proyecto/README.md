# Memoria del proyecto

Es el cuaderno del proyecto: lo que se decidió y aprobó, para que nadie tenga que empezar de cero ni releer todo.

| Archivo | Qué guarda |
|---|---|
| `cliente.md` | Datos del cliente, contacto responsable, marca, referencias |
| `requerimientos-aprobados.md` | La versión aprobada por el cliente. Es la regla del alcance |
| `decisiones.md` | Fichas de decisiones de arquitectura y producto |
| `cambios.md` | Solicitudes de cambio y su resultado |
| `aprobaciones.md` | Registro de los 5 controles |
| `mantenimiento.md` | Plan, horas usadas, tickets y costos de cada mes |
| `presupuesto-ia.md` | Tope de gasto de IA y gasto por sprint |
| `reglas-de-precio.md` | Reglas de precio del dueño (en `fabrica-base`, se copian a cada proyecto) |

Nunca se guardan aquí claves, contraseñas ni accesos.
