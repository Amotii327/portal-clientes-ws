# Cierre de sprint

## Construcción
- [ ] Todas las historias del sprint tienen pull request.
- [ ] Cada pull request fue revisado por QA (nadie se revisó a sí mismo).
- [ ] Las pruebas automáticas pasan; ninguna se desactivó.
- [ ] Sin claves en el código.

## Calidad
- [ ] Criterios de aceptación probados uno a uno.
- [ ] Separación entre empresas y permisos probados.
- [ ] Pantallas revisadas con `revision-de-pantallas.md`.
- [ ] Informe de pruebas lleno.

## Demo
- [ ] Versión de prueba publicada con link.
- [ ] Acta de sprint llena.
- [ ] Pedidos fuera de alcance convertidos en solicitudes de cambio.
- [ ] Gasto de IA del sprint anotado en `presupuesto-ia.md`.
- [ ] Aprobación del dueño (control 4) antes de mostrar al cliente.
- [ ] Portal actualizado con el avance.
